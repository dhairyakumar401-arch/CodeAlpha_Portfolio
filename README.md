# ✨ LUMORA Portfolio

### Personal Portfolio Website – Dhairya Kumar

A modern, responsive and interactive personal portfolio built using HTML, CSS and JavaScript. LUMORA showcases my skills, education, projects and resume through a premium glassmorphism design.

## 🌐 Live Website

[Visit LUMORA Portfolio](https://dhairyakumar401-arch.github.io/CodeAlpha_Portfolio/)

## 🚀 Features

- Modern glassmorphism UI
- Animated grid background
- Multiple color themes
- 3D hover effects
- Typing animation
- Responsive design
- Skills and education sections
- Project showcase with filters
- Resume PDF download
- Contact form with email preparation
- Scroll reveal animations
- Back-to-top button

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/dhairyakumar401-arch/CodeAlpha_Portfolio.git
```

2. Open the project folder.
3. Open `index.html` using VS Code Live Server.
